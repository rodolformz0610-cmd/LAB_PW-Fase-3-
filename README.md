# LAB_PW-Fase-3-

Se tiene que usar HTML5, CSS3, JavaScript nativo y PHP con PDO. El diseño conserva su logotipo morado, menú centrado, fondo blanco, tarjetas horizontales, sombras suaves y botones oscuros/rojos. Las imágenes son fotografías de sustitución, no las imágenes originales de los bosquejos.

# Pasos para usar en Windows

1. Extraiga el .zip, entre a la carpeta llamada nexo y dé click en INICIAR-DEMO.
2. En caso de que PHP no se haya podido instalar, el iniciador descarga una versión portable de su sitio oficial y verifica su SHA-256. Se guarda en storage/, dentro del proyecto; no modifica el PHP del sistema.
3. Una vez ejecute la página con INICIAR-DEMO, abra su navegador y visite "http://127.0.0.1:8765/cursos.html".
